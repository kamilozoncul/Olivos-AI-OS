# Contributing to Olivos AI OS

Thank you for your interest in contributing to Olivos AI OS.

Olivos AI OS is an AI-powered e-commerce operating system designed with modular architecture, intelligent agents, knowledge systems and automation workflows.

This document explains the contribution standards and development workflow.

---

# Development Workflow

## 1. Create a Branch

All changes should be developed in a separate branch.

Example:

```bash
git checkout -b feature/new-agent
```

Branch naming:

```
feature/
bugfix/
documentation/
improvement/
```

---

# 2. Make Changes

Before adding new features:

* Review existing architecture
* Follow current folder structure
* Keep modules independent
* Update documentation when necessary

---

# 3. Commit Standards

Commit messages should clearly describe the change.

Examples:

```
Add SEO Agent architecture

Update Meta Ads decision rules

Improve knowledge base structure

Fix workflow documentation
```

---

# 4. Pull Request Guidelines

Before submitting a pull request:

Checklist:

* Code or documentation is tested
* Changes are documented
* No sensitive information is included
* Existing architecture is respected

---

# Project Principles

## Modular Design

Each component should have a clear responsibility.

## AI First Approach

Systems should support intelligent decision making.

## Documentation Driven Development

Important changes must be documented.

## Data Driven Decisions

Recommendations should be based on measurable information.
