CTR ANALYSIS

=========================================================

IF

CTR < %0.80

THEN

Kreatif zayıf olabilir.

Hook analiz edilmeli.

Headline analiz edilmeli.

Primary Text analiz edilmeli.

Audience tekrar değerlendirilmeli.

---------------------------------------------------------

IF

CTR %0.80 - %1.50

THEN

Ortalama performans.

Yeni kreatif testleri öner.

---------------------------------------------------------

IF

CTR %1.50 - %2.50

THEN

İyi performans.

CPA ve ROAS birlikte analiz edilmeli.

---------------------------------------------------------

IF

CTR > %2.50

THEN

Kreatif güçlü.

Landing Page performansı incelenmeli.

---------------------------------------------------------

IF

CTR yüksek

AND

CPA yüksek

THEN

Sorun reklam değildir.

Landing Page

Checkout

Offer

analiz edilmelidir.

---------------------------------------------------------

IF

CTR düşük

AND

CPM yüksek

THEN

Audience çok dar olabilir.

Audience genişlet.

---------------------------------------------------------

IF

CTR düşük

AND

Frequency yüksek

THEN

Creative Fatigue oluşmuş olabilir.

Yeni kreatif hazırlanmalıdır.

==================================================================================================================

CPC ANALYSIS

=========================================================

IF

CPC artıyor

AND

CTR düşüyor

THEN

Kreatif kalitesi düşmüş olabilir.

---------------------------------------------------------

IF

CPC yüksek

AND

CTR yüksek

THEN

Audience rekabeti yüksek olabilir.

---------------------------------------------------------

IF

CPC düşük

AND

Purchase düşük

THEN

Trafik kalitesi analiz edilmelidir.

---------------------------------------------------------

IF

CPC düşüyor

AND

ROAS artıyor

THEN

Mevcut yapı korunmalıdır.

==================================================================================================================

CPM ANALYSIS

=========================================================

IF

CPM yükseliyor

CTR sabit

THEN

Rekabet artmış olabilir.

---------------------------------------------------------

IF

CPM yüksek

CTR düşük

THEN

Audience yeniden değerlendirilmeli.

---------------------------------------------------------

IF

CPM düşük

CTR yüksek

THEN

Kreatif avantajlı durumda.

Ölçekleme değerlendirilebilir.
