# IdeaSoftAgent Output Format

## Purpose

This document defines the standard output format used by IdeaSoftAgent.

All audits, recommendations and operational reports must follow this structure.

---

# Store Audit Report

```
Store Analysis

↓

Current Status

↓

Findings

↓

Issues

↓

Recommendations

↓

Action Plan

↓

Expected Business Impact
```

---

# 1. Report Information

Include:

```
Report Name:

Store:

Date:

Analysis Period:

Prepared By:

IdeaSoftAgent
```

---

# 2. Store Overview

Evaluate:

- Homepage
- Navigation
- Categories
- Products
- Mobile Experience
- Technical Health

Overall Score:

0–100

---

# 3. Product Evaluation

For each issue include:

```
Product:

Issue:

Business Impact:

Priority:

Recommendation:
```

---

# 4. Category Evaluation

Include:

```
Category:

Finding:

SEO Status:

Navigation Quality:

Recommendation:
```

---

# 5. Technical Findings

Report:

- Broken links
- Missing images
- Empty metadata
- Duplicate content
- Mobile issues
- Performance opportunities

Severity:

- Critical
- High
- Medium
- Low

---

# 6. Marketing Readiness

Evaluate:

- Landing pages
- Campaign pages
- Coupon setup
- Featured products
- Upsell opportunities
- Cross-sell opportunities

---

# 7. Prioritized Action Plan

## Immediate (0–7 Days)

List critical fixes.

## Short Term (7–30 Days)

List optimization tasks.

## Long Term (30+ Days)

List strategic improvements.

---

# 8. Expected Business Impact

Estimate impact on:

- Customer Experience
- SEO
- Conversion Rate
- Revenue
- Operational Efficiency

---

# 9. CEO Summary

Every report ends with:

```
Top Priority:

Biggest Opportunity:

Expected Result:

Recommended Next Action:
```

---

# Output Rules

Every report must be:

- Practical
- Clear
- Actionable
- Business-focused
- Prioritized

Avoid:

- Generic suggestions
- Technical jargon without explanation
- Unprioritized recommendations

---

# Core Principle

Every audit should lead to measurable improvements that increase customer satisfaction and business growth.
